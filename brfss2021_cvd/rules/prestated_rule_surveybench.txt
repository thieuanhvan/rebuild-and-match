ALIVE as a separate paper requires ALL of:
 A1 Reach: >= 5 published papers (Europe PMC or Crossref, any year) that use the file, OR >= 50 Kaggle notebooks.
 A2 Rebuild: the file is rebuilt from the official raw survey file with multiset match >= 0.99, OR the attempt
    shows precisely which step cannot be reproduced (that itself is a finding).
 A3 >= 2 undocumented construction decisions verified against raw data, of which >= 1 changes the label or the
    meaning/unit of a feature, and >= 1 belongs to a defect class NOT in P9 (P9 classes: label recode vs
    documentation, dropped design variables, complete-case deletion of valid answers, outcome/feature drift
    across versions, imputed race). Points already raised publicly (discussion tab, papers) count only as cited.
 A4 Consequence: at least one decision changes a typical model result under the P9 AUC rule (median paired
    difference >= 0.01, beyond seed range, bootstrap CI excludes 0) or changes an effect estimate beyond its CI.
    (Tested only if A1-A3 pass.)
KILL if: a paper, preprint, notebook or discussion post already rebuilds the file from raw data and reports the
 same defects; or A1 fails; or the only defects are P9 classes (then: P9 row or nothing).
NARROW if: A1-A3 pass but A4 fails (documentation note at most; decide with the student).

Order: literature search (Europe PMC, Crossref, arXiv) for each candidate -> download official raw file
(public CDC, no login) -> rebuild pilot (Kaggle/UCI copies: student downloads if login needed) -> two blind
screeners -> verdict. One external API process at a time; UA research-script/1.0; no NCBI E-utilities.
